# LES-003 — Engineering culture is causal provenance

**Status:** accepted for first implementation  
**Source:** human discussion, 2026-08-11

## Observation

Requirements frequently underdetermine implementation and design choices. Engineers choose among several valid approaches partly because of accumulated habits, values, and prior exposure. Spiral Developer currently contains Muze preferences mixed into apparently universal process guidance.

## Lesson

Make active engineering culture explicit, versioned, shareable, defeasible, and referenceable from design/implementation decisions.

A useful explanation should be able to distinguish:

- “X exists because requirement Y requires it”; from
- “X was implemented this way because active culture preference Z shaped the choice.”

## Scope

Culture model plus a separation-of-concerns correction to Spiral core.
