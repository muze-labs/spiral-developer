# LES-001 — Agent autonomy depends on verification architecture

**Status:** adopted into core trust model  
**Source:** human discussion, 2026-08-11

## Observation

A process built around causal evidence, verification, immutable proposed history, and human governance permits an AI coding agent to work with materially more freedom than workflows that try to control correctness through continuous human steering.

## Lesson

Describe Spiral explicitly as **trust but verify**. Agent autonomy should be justified by the surrounding verification architecture, not by confidence that the model will behave correctly.

Verification must move before actions whose consequences would be unacceptable before review or adequate rollback.

## Scope

Spiral core: this describes the intended trust architecture rather than a Muze-specific engineering preference.
