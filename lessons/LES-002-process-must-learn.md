# LES-002 — The process must be allowed to learn

**Status:** adopted as process-evolution mechanism  
**Source:** human discussion, 2026-08-11

## Observation

Dogfooding and project work repeatedly expose weaknesses in the production environment itself. A fixed methodology would either preserve known defects or force improvements to happen informally outside the causal record.

## Lesson

Record causally useful lessons and allow them to change project practice, culture profiles, and—when sufficiently general—the Spiral process itself.

A lesson is evidence-informed and defeasible; it should not automatically become a new universal rule.

## Scope

Spiral core: the ability to revise the production environment is necessary for an evidence-driven development process to improve rather than calcify.
