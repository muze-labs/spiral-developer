# Lesson: Incomplete intake must remain visible

## Observation / evidence

Interpreted evidence: `UND-PROCESS-002` (from `SRC-PROCESS-002`).

The guided brownfield intake deliberately avoided a fixed questionnaire. In practice, that made it easy for an agent to skip a topic and continue without either the human or agent noticing that the project frame remained partial.

## Lesson

Intake needs explicit state and complete topic coverage without becoming a rigid form. Every required topic must receive an explicit disposition; `Unknown`, `Not relevant`, and deliberate deferral are valid. Until all topics are dispositioned and the human confirms the frame, every substantive intake interaction should visibly say that intake is incomplete and list what remains.

## Scope

Brownfield onboarding and material project reframing where durable project context is missing or stale.

## Confidence / limits

High confidence in the visibility requirement from dogfooding. The exact topic set should remain small and may evolve; completion should not require fabricated certainty.

## Proposed consequence

Persist `Incomplete/Complete/Stale` intake state and a compact required-topic checklist in project context; update prompts and process guidance so silent omission cannot masquerade as completed intake.
