# Risk-discovery profile: User-facing interaction

Use when people directly interact with the software. This is a discovery prompt, not a universal requirement set.

Consider whether material project risk exists around:

- important tasks that users cannot discover, understand, or complete;
- interaction paths that exclude relevant input modes, assistive technology, devices, languages, or user capabilities;
- error states that are hard to recover from or silently lose work;
- user-visible behavior that differs from what support/docs/product assumptions claim;
- feedback collection that measures clicks or screenshots rather than meaningful task outcomes;
- irreversible or high-impact actions whose consequences are not clear enough to users;
- important flows whose actual usage/reliability is not observable.

Select or narrow this profile according to the project's actual audience and commitments.
