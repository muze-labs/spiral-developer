# Intake Profiles

These are optional plain-Markdown suggestion sources for brownfield intake and project reassessment.

- `risk-discovery/` suggests classes of project-specific problems worth investigating.
- `metrics/` suggests measurements or qualitative outcomes that may matter for a project posture.

Profiles are not requirements, automatic findings, or project truth. The intake should explicitly select, exclude, narrow, or extend them with human input. A finding becomes a project concern only when project-specific evidence and judgment support it.

Keep this layer deliberately informal while dogfooding. Repeated custom answers may justify new or revised profiles later.
