# Metric profile: Exploratory product

This profile suggests questions for projects primarily trying to learn whether a product/problem framing is useful. It is not a maturity scorecard.

Possible useful signals include:

- intended users can complete the core exploratory task;
- observed user corrections or changed behavior reveal assumptions quickly;
- time/cost to test a consequential assumption;
- number or importance of unresolved assumptions blocking commitment;
- reversibility of current product/technical choices;
- qualitative evidence that the proposed outcome matters to the intended audience.

Do not optimize adoption, throughput, polish, or infrastructure metrics merely because they are easy to measure if the project is still trying to learn whether the underlying direction is right.
