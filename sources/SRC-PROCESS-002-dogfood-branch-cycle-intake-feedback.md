# Source: Dogfooding feedback on branch discipline, cycle sizing, and intake

## Human direction

After reviewing SimplyStore work performed with Spiral Developer, the human identified three process weaknesses:

1. **Branch drift:** “Did not notice the incorrect branch name, that is something we should try to fix in spiral developer itself.”
2. **Cycle sizing:** “I also noticed a tendency to begin with very small cycles, which is fine for the start, but should not be the default later.”
3. **Intake completeness:** “And finally, we need a more explicit intake. Currently it is easy to skip steps, and you won't realize it. Either walk through the intake entirely and always, or note at each interaction that intake is not finished yet.”

The human then supplied the latest Spiral Developer repository and requested that these changes be applied to it.
