## Evidence weighting supplied by the human reviewer

The repository is not uniformly authoritative evidence of Muze culture.

Use this weighting when interpreting it:

- **strong evidence:** book prose, explicit project/design notes, repository history around deliberately revised ideas, and implementation/design decisions that have received human review;
- **moderate/corroborating evidence:** repeated repository structures or implementation choices that align with stronger sources;
- **provisional evidence:** the current `solid-tools` package, because it is still undergoing human review and change;
- **weak evidence:** implementation details of the margin-notes application, because it was mostly vibe-coded with substantial feedback but its code itself had not yet been human-reviewed.

The weak/provisional categories may show what an agent produced or what the project experimented with. They must not be promoted to organization culture merely because they exist in the repository.
