# Repository Bootstrap Prompt

Use Spiral Developer as the governing process for this repository.

Read, in order:

1. `AGENTS.md`
2. `docs/01-vision.md`
3. `docs/02-brownfield-adoption.md`
4. `docs/03-development-loop.md`
5. `docs/04-causal-artifact-model.md`
6. project-specific culture/context already present

Then inspect the repository only far enough to support the next real piece of work.

Do **not** attempt to reconstruct complete project history.

Produce:

- a concise project-context draft if one does not exist;
- the relevant culture sources/constraints;
- an audit scope/baseline;
- known opaque vs characterized areas relevant to current work;
- a proposal for the first bounded request/cycle to bring under Spiral Developer.

Separate explicit/evidenced/inferred/unknown legacy knowledge.
